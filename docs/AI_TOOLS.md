# AI tools used

- **Claude Code (Claude Opus), desktop app.** I used it as a pair programmer.
  We discussed the design together: the choice of library, the task ladder,
  the exploit list, and splitting the work between the office machine (no
  Docker) and home. It drafted most of the code and the first drafts of these
  notes, and it ran the local checks. I reviewed the design decisions and
  the results and edited the write-ups.
- **Agent under test:** a local open model via Ollama (see docs/RESULTS.md,
  section 3). No paid APIs were used for the agent runs.
